# 🚀 Trilha Backend - Sprint 2 | Desafio de POO em Java

Repositório dedicado às entregas e desafios práticos da **Sprint 2** da Trilha Backend. Este projeto tem como objetivo a aplicação prática de conceitos de **Programação Orientada a Objetos (POO)** e estruturas condicionais utilizando a linguagem Java.

---

## 🛠️ O que foi desenvolvido?

O programa foi estruturado para atender aos requisitos propostos no desafio da sprint:

### 👤 Exercício 1 – Classe Pessoa
* Criação da classe `Pessoa` contendo 3 atributos (sendo a **idade** o atributo obrigatório).
* Instanciação de 3 objetos diferentes (`p1`, `p2` e `p3`) com dados distintos.
* Implementação de uma estrutura condicional (`if / else if / else`) para comparar as idades e exibir no console qual das pessoas é a mais velha.

### 🚗 Exercício 2 – Classe Carro
* Criação da classe `Carro` contendo 3 atributos (sendo o **ano** o atributo obrigatório).
* Instanciação de 2 objetos diferentes (`carro1` e `carro2`).
* Modificação do valor de um atributo em apenas um dos objetos para demonstrar o isolamento de instâncias na memória.
* Inclusão de um comentário técnico no código explicando **por que a alteração em um carro não afetou o outro**.

---

## 💻 Como executar o projeto

1. Certifique-se de ter o **JDK (Java Development Kit)** instalado em sua máquina.
2. Clone este repositório ou baixe os arquivos fonte (`.java`).
3. Abra o projeto em sua IDE de preferência (IntelliJ IDEA, Eclipse, VS Code, etc.).
4. Execute a classe principal (`Sprint2Backend.java` ou equivalente).
